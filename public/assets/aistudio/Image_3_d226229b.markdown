## Brand & Style

This design system blends **Frosted Glassmorphism** with **Fluid Liquid Light** on a deep, obsidian foundation. It targets design-forward software engineers, tech founders, and digital pioneers who expect cutting-edge polish, fluid tactility, and high-energy visual feedback.

The interface evokes depth, precision, and ambient luminescence. Instead of flat static cards, surfaces exist as multi-layered crystalline sheets suspended over slowly shifting optical mesh gradients. High-translucency materials (`backdrop-blur-2xl`), refraction highlights, and hyper-saturated neon accents produce an interface that feels alive, responsive, and physically manufactured from optical-grade glass.

## Colors

The color architecture is built around an ultra-deep obsidian space lit by electric spectral energy:

- **Primary (`#00F5FF` - Neon Cyan):** Key action driver, critical states, optical specular reflections, and intense focal glows.
- **Secondary (`#8A2BE2` - Electric Violet):** Secondary interactions, complex gradient endpoints, and chromatic aberration highlights.
- **Tertiary (`#2563EB` - Vibrant Cobalt):** Structural atmospheric glow, foundation active states, and mid-tone gradient balances.
- **Accent Soft Emerald (`#10B981`):** Success confirmations, live telemetry, and organic dynamic alerts.
- **Neutral Base (`#05070E` - Obsidian Void):** The dark substrate that allows high-translucency glass and iridescent blurs to achieve peak contrast without eye fatigue.

### Surface Color Tokens
- **Canvas Base:** `#05070E`
- **Glass Panel Surface:** `rgba(13, 18, 36, 0.45)` with `backdrop-filter: blur(24px) saturate(190%)`
- **Glass Interactive Surface:** `rgba(255, 255, 255, 0.06)` (default) / `rgba(255, 255, 255, 0.12)` (hover)
- **Glass Specular Border:** `linear-gradient(135deg, rgba(255, 255, 255, 0.22) 0%, rgba(255, 255, 255, 0.03) 60%, rgba(0, 245, 255, 0.2) 100%)`

## Typography

The type system balances technical precision with organic legibility.

- **Headlines & Metric Accents (`Space Grotesk`):** Delivers a technical, futuristic edge. Headings feature tight negative letter-spacing for structural tension, lending authority to quantitative dashboards and product heroes.
- **Body & Controls (`Plus Jakarta Sans`):** Provides soft geometric forms, balanced apertures, and crisp readability on dark translucent backgrounds.
- **Contrast & Hierarchy:** Primary headers utilize semi-transparent white-to-slate fills (`#FFFFFF` to `#94A3B8`) or light gradient masking (`#FFFFFF` to `#00F5FF`) to emphasize depth without overpowering UI content.

## Layout & Spacing

The layout philosophy uses a **dynamic fluid container** architecture. Glass panels expand with consistent structural padding to keep internal elements isolated from background ambient flares.

### Grid System
- **Desktop (1280px+):** 12-column grid, `margin: 3rem`, `gutter: 1.5rem`. Max container width: 1440px.
- **Tablet (768px - 1279px):** 8-column grid, `margin: 2rem`, `gutter: 1.25rem`.
- **Mobile (<767px):** 4-column grid, `margin: 1.25rem`, `gutter: 1rem`.

### Spacing Principles
- Heavy negative outer spacing balances luminous, high-density glass modules.
- Nested components within translucent panels must maintain at least `space-md` (16px) separation from panel borders to avoid visual collision with light-refraction edges.

## Elevation & Depth

Depth is conveyed through **chromatic optical layering** and **variable refraction**, replacing traditional black drop shadows with luminous glass metrics.

1. **Ambient Background Layer (Level 0):** Deep `#05070E` with 2–3 blurred radiant orbs (e.g., `#8A2BE2` at 20% opacity and `#00F5FF` at 15% opacity, `blur(120px)`).
2. **Base Glass Paneling (Level 1):** Background `rgba(13, 18, 36, 0.45)`, `backdrop-filter: blur(24px)`, border: `1px solid rgba(255, 255, 255, 0.08)`. Shadow: `0 8px 32px -4px rgba(0, 0, 0, 0.5)`.
3. **Elevated Floating Cards / Modals (Level 2):** Background `rgba(20, 26, 50, 0.65)`, `backdrop-filter: blur(36px) saturate(200%)`. Border: `1px solid rgba(255, 255, 255, 0.18)` with an inner top highlight `inset 0 1px 1px 0 rgba(255, 255, 255, 0.35)`. Shadow: `0 20px 48px -10px rgba(0, 0, 0, 0.7), 0 0 24px -2px rgba(0, 245, 255, 0.15)`.
4. **Specular Lighting & Edge Glows:** Card borders use subtle gradients from `rgba(255, 255, 255, 0.25)` at the top-left to `rgba(138, 43, 226, 0.2)` at the bottom-right, simulating light entering an angled glass prism.

## Shapes

The design uses **Rounded (`roundedness: 2`)** shaping. Primary interface elements feature base `0.5rem` (8px) corners, standard cards and panels use `1rem` (16px), and prominent feature containers scale up to `1.5rem` (24px).

Pill forms (`rounded-full`) are reserved exclusively for contextual tags, status indicators, and micro-actions to maintain geometric order and contrast against large rectangular glass panels.

## Components

### Buttons
- **Primary Action:** Solid-to-luminous gradient (`linear-gradient(135deg, #00F5FF 0%, #2563EB 100%)`), text `#05070E` bold, with an outer atmospheric glow `box-shadow: 0 0 20px rgba(0, 245, 255, 0.4)`. On hover, scale `1.02` with amplified glow radius.
- **Glass Secondary:** Fill `rgba(255, 255, 255, 0.05)`, border `1px solid rgba(255, 255, 255, 0.15)`, text `#F8FAFC`. On hover, fill shifts to `rgba(255, 255, 255, 0.1)` with border brightening to `rgba(0, 245, 255, 0.4)`.

### Cards & Panels
- **Structure:** `backdrop-filter: blur(24px)`, background `rgba(13, 18, 36, 0.5)`.
- **Edge Detailing:** `1px` continuous border with dual-layer highlights: an outer ambient shadow and an inner specular stroke `inset 0 1px 0 0 rgba(255, 255, 255, 0.2)`.

### Input Fields
- Dark translucent fill `rgba(7, 10, 20, 0.6)` with inset border `rgba(255, 255, 255, 0.1)`.
- Placeholder text in `#64748B`.
- **Focus State:** Border transitions to `#00F5FF` with a subtle field glow `0 0 12px rgba(0, 245, 255, 0.25)` and zero layout shift.

### Chips & Badges
- Pill silhouette (`rounded-full`), padding `0.25rem 0.75rem`.
- Background `rgba(0, 245, 255, 0.08)`, border `1px solid rgba(0, 245, 255, 0.25)`, text `#00F5FF`.
- Pulsing glass status dot with a soft radial glow when signalling live connectivity.

### Checkboxes & Radio Buttons
- Custom glass squares/circles (`18px`) with `rgba(255, 255, 255, 0.08)` fill and `1px solid rgba(255, 255, 255, 0.2)`.
- Active state fills with `#00F5FF` using a sharp dark check mark (`#05070E`) and an ambient neon glow.

### Data Displays & Charts
- Glass backdrop layers behind metrics.
- Area graphs feature gradient fills fading from neon cyan/violet at 30% down to 0% opacity over the glass bed.
- Grid lines styled with low-opacity white dashes (`rgba(255, 255, 255, 0.06)`).
